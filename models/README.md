# Realizer Free Model Registry

## Wan 2.1 T2V 1.3B

**Status:** primary open model for Realizer V1.

**License:** Apache-2.0 (verify upstream terms before each commercial release).

**Official model:** Wan-AI/Wan2.1-T2V-1.3B

**Capabilities:** Text-to-video. The broader Wan 2.1 family also includes image-to-video and VACE variants.

**Inference:** The model is free/open; GPU compute is a separate infrastructure cost. Realizer does not embed model weights in this repository.

## Policy

Model files stay outside Git. The application stores only model metadata, license information, and provider configuration. Every model added for the commercial Realizer product must have its license and commercial-use conditions reviewed before release.
